## Slide 9: Profit & Loss Calculation Logic
**Title:** Automated P&L System

**Calculation Formula:**
```
Profit/Loss = Total Sales - Total Expenses
Profit Margin = (Profit/Loss / Total Sales) × 100%
```

**Features:**
- Daily breakdown
- Monthly aggregation
- Color-coded indicators (Green = Profit, Red = Loss)
- Percentage calculations
- Trend analysis

**Example:**
- Sales: KSh 50,000
- Expenses: KSh 30,000
- **Profit: KSh 20,000** (40% margin)
